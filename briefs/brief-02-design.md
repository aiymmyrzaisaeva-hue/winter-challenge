# 2. Оформление

- Сохранить зимнюю палитру со светлым фоном, бордовым текстом и золотистым солнцем. Пока видео готовится, показать фото ёлки. После добавления видео использовать фото как постер, если нет отдельной обложки.
- Для первой страницы взять из [lp-1](../assets/lp-1.png) личное обращение и крупный акцентный заголовок. Выделить рядом просмотры и число подписчиков, чтобы связь была видна сразу.
- Для второй страницы взять из [lp-2](../assets/lp-2.png) крупный заголовок, левое выравнивание и нумерованные шаги. После шагов поставить кнопку Telegram в том же потоке.
- Для заголовков использовать кириллическую антикву, для цифр, шагов и кнопки — читаемый гротеск. Использовать короткие абзацы и заметный фокус. Оформить текст средствами страницы, сохранив иллюстрации как референсы.
